# z-lib Android 0.1.3 稳定版

## 新增功能

1. 首页新增图书分区管理：可自定义添加 zlib 官方分类，长按拖动调整顺序。
2. 搜索接入微信读书源（需先登录微信读书）。
3. 微信读书的书籍可加入书架，也可一键跳转微信读书 App 阅读。
4. 微信读书书籍详情新增「热门划线」：支持横滑浏览、查看全部（瀑布流）。
5. 微信读书栏支持从本地导入书籍，也可移除。
6. 新增扫码登录 + 连接信息导出/导入：首次登录用另一台设备扫码；登录后可在右上角导出连接信息，换设备或重装后粘贴即可恢复（建议导出后尽快使用，长期存放可能失效）。
7. 「我的」新增「历史版本」：可查看每个版本的更新内容和发布时间，并下载历史版本。

## 优化与修复

1. 打通「zlib 下载 → 微信读书导入 → 跳转阅读」的完整流程。
2. 列表和详情页下滑时，右侧固定显示「回到顶部」「搜索」悬浮按钮。
3. 历史栏新增搜索，可快速筛选书籍。
4. 新增版本更新提醒：有新版会弹窗提示，可勾选「以后不再提醒」；之后仍可在「历史版本」查看更新。
5. 收藏同步到 zlib 账号，换设备登录后收藏记录保留。
6. 修复下载失败后重试会重复消耗下载次数的问题。
7. 书籍详情页支持长按选中复制文字。
8. 历史记录删除支持选择「本地删除」或「云端删除」，并支持长按多选批量操作。
