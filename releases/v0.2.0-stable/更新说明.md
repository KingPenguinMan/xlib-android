# xlib Android 0.2.0 稳定版

这次是一个「降门槛」的版本：不登录也能先逛了。

## 新增

1. 未登录可浏览：打开 App 就能看到「热门推荐」「新书上架」，以及自己添加的分类分区。
2. 未登录可搜索：直接搜书名、作者或关键词，结果列表正常显示。
3. 点书引导登录：未登录时点某本书，会弹出登录框引导登录，而不是报错。

## 说明

- 书籍详情、下载、在线预览、收藏、历史记录、微信读书书架仍需登录（zlib 官方接口要求）。
- 已登录用户使用方式不变。
