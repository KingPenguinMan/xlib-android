## 安装兼容性

如果安装时提示签名冲突，请先备份账户设置、收藏及本地下载，确认备份后再卸载旧版安装；卸载可能清除应用数据。相同维护者签名体系下的版本可正常升级。

## 下载

- arm64-v8a：大多数 Android 手机和平板。
- armeabi-v7a：32 位 ARM Android 设备。
- x86_64：相应架构的模拟器或设备。

此版本是普通 Android 正式版，不是 Kindle CPU 软件渲染兼容包。最低 Android 7.0。旧版若仍查询 Gitee 更新，请手动安装一次此版，后续使用 GitHub 更新渠道。
