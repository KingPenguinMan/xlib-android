# xlib 0.3.0 稳定版

本次更新带来了书单、书籍评价等新功能，同时修复了若干问题，并将应用更名为 xlib，以便与官方版本区分。

## 新增功能

1. **书单功能**：可以把喜欢的书整理成书单，方便集中管理和分享。
2. **书籍评价 + 作者页**：详情页新增「推荐 / 不推荐」评分，显示评分人数与评论条数；点击作者名可进入该作者的专属页面，查看 TA 在库里的其他作品。
3. **回血（赞赏）**：「我的」页面新增「回血」入口。xlib 一直免费、开源、无广告，如果你愿意，可以扫码请我们喝杯咖啡——金额随意，不赞赏也完全不影响使用。
4. **GitHub 历史版本链接**：「我的」页面可查看历史版本，方便回退或下载旧版。
5. **墨水屏（kindle）主题版**：黑白灰阶、无动画，适配墨水屏设备。

## 优化与修复

1. **新增 HTML 保底链路**：正常情况下仍走官方接口；只有官方链路不可用时，才自动切到网页版链路取数据，不影响日常使用。
2. **修复下载失败时的缓存堆积**：下载失败后不再残留无效缓存，避免白白占用存储空间。
3. **应用更名为 xlib**：与官方版本区分开，避免误会。功能和使用方式不变。
